# OAR: Scoring transcriptional shifts in scRNAseq

OAR (observed at random) score is a measure of transcriptional shifts
among cells, allowing cell prioritization for downstream applications.
For best results, test a group of similar cells where you expect some
heterogeneity - i.e. one cell type across various biological samples or
conditions.
